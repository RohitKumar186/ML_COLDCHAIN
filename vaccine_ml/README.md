# Vaccine Cooling Box ML

Project scaffold for processing sensor readings and managing cooling and temperature models.

## Structure

- `data/raw/`: incoming sensor data
- `data/processed/`: prepared training data
- `models/`: serialized model artifacts
- `src/`: application and model code

## Run

From the `vaccine_ml` directory:

```bash
pip install -r requirements.txt
python -m src.main
```
